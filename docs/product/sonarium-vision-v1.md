# Sonarium Product Vision v1

## Product definition
Sonarium is a **spectral instrument and processor** for realtime audio sculpting. It combines tactile spectral-domain interaction, high-clarity visualization, and modular processors in both:

- a standalone application
- plugin forms for modern host workflows

It is Linux-first (PipeWire/JACK/LV2/CLAP aware) while remaining cross-platform friendly.

## Who Sonarium is for

- **Sound designers** creating novel timbres, transformations, and hybrid textures.
- **Mix engineers/producers** applying selective spectral shaping beyond static EQ.
- **Live performers** needing expressive, visual, gesture-driven effects.
- **Experimental artists/research-adjacent creators** exploring unusual frequency-domain mappings.

## Primary use cases

### 1) Spectral sculpting
Directly draw and reshape spectral energy over time/frequency to carve tone, remove clutter, and emphasize character.

### 2) Sound design
Generate evolving effects via spectral delay, warp, smear, and pitch remapping for pads, transitions, impacts, and abstract layers.

### 3) Mixing
Use controlled spectral gate/EQ behavior to improve separation and dynamic clarity in specific spectral regions.

### 4) Performance
Map macros and modulators to perform expressive sweeps, pulses, and spectral morphs in realtime.

### 5) Experimental processing
Create intentionally nontraditional spectral outcomes for generative, ambient, noise, and electroacoustic practices.

## v1 feature scope

## Core visualization
- **Spectrogram view** (scrolling, high-contrast, musically readable).
- **Magnitude view** (line/bar hybrid options).
- **Pre/Post display** for trust and comparison.
- **Zoom controls** (frequency and value ranges).
- **Freeze** mode for detailed inspection/editing.

## Core processors
- **Spectral Draw EQ**
- **Spectral Gate**
- **Spectral Smear**
- **Spectral Delay**
- **Spectral Warp**
- **Spectral Pitch Map**

## Modulation
- **LFO** (rate/depth/shape with sync options where host data exists).
- **Envelope follower** (audio-reactive control source).
- **Macro controls** (user-assignable high-level performance knobs).

## Workflow essentials
- **Preset management** (save/load/browse/tag baseline).
- **Undo/redo** for safe experimentation.
- **A/B compare** for fast decision-making.
- **Host automation exposure** (plugin contexts).

## Explicitly deferred beyond v1

- Advanced collaborative/cloud preset exchange.
- Multi-instance inter-communication.
- MIDI MPE deep expression layer (beyond basic mapping).
- Fully modular node-graph environment.
- ML-assisted source separation or “auto spectral repair”.
- Full mastering-grade transparency suite.
- Immersive/multichannel surround-specific toolset.
- Oversampled nonlinear hybrid processing chains.

## Product qualities Sonarium v1 must hit

- Feels like an **instrument**, not a static analyzer.
- Delivers **reliable realtime response** on modern Linux production systems.
- Maintains **clear sonic intent** through visual feedback.
- Allows **musical exploration without destructive confusion**.
